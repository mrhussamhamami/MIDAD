# مِداد | MIDAD
منصة عربية لتصميم شهادات التكريم المدرسي، تعمل بالكامل داخل المتصفح بدون خادم.

## التشغيل والنشر
افتح `index.html` في متصفح حديث. للنشر على GitHub Pages ارفع `index.html` و`style.css` و`app.js` إلى جذر المستودع.

## المزايا
- عدة مدارس بهوية مستقلة: شعار، توقيع، ختم، لون.
- الطلاب: إضافة يدوية أو استيراد CSV، وطباعة شهادة لكل طالب دفعة واحدة.
- الاستوديو: 4 أنماط، قوالب جاهزة لكل مناسبة، خيارات تخطيط (حجم الاسم والنص، موقّع ثانٍ، سطر إضافي، إخفاء الشعار/الختم/الرقم)، معاينة حية.
- الإخراج: طباعة A4 أفقية أو PDF، تنزيل PNG، مشاركة عبر قائمة الجهاز.
- أرشيف قابل للبحث، وإحصاءات الإنجاز.
- تنقل بدون إعادة تحميل مع دعم زر الرجوع، ووضع ليلي يُحفظ اختياره، وتصميم متجاوب.
- نسخ احتياطي واستعادة بصيغة JSON.

## ملاحظات
- البيانات تُحفظ في متصفحك فقط ولا تُزامَن بين الأجهزة. لا توجد حسابات ولا صلاحيات، فلا تعتمد على الموقع كحماية للبيانات.
- استيراد Excel: احفظ الملف بصيغة CSV أولاً.
- صورة PNG قد تخرج بخط بديل إن لم يكن خط الشهادة محمّلاً في النظام.
