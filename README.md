# مِداد | MIDAD
منصة عربية محلية لتصميم الشهادات والتكريم المدرسي.

## التشغيل
افتح `index.html` في متصفح حديث. لا يحتاج المشروع إلى خادم.

## المزايا الحالية
- إدارة مدارس متعددة وبيانات الهوية لكل مدرسة.
- إدارة الطلاب يدوياً واستيراد CSV وExcel (يتطلب اتصالاً لتحميل مكتبة XLSX).
- استوديو تصميم بشهادة A4 أفقية ومعاينة مباشرة وثلاثة أنماط.
- حفظ الشهادات في الأرشيف وإعادة فتحها للطباعة.
- الطباعة أو الحفظ PDF عبر نافذة الطباعة.
- تصدير نسخة احتياطية واستعادتها بصيغة JSON.
- وضع ليلي وتصميم متجاوب.

## ملاحظات
- البيانات تحفظ محلياً في المتصفح ولا تتم مزامنتها بين الأجهزة.
- احتفظ بنسخة احتياطية دورية من صفحة النسخ الاحتياطي.
- استيراد XLSX يعتمد على مكتبة SheetJS من CDN؛ CSV متاح أيضاً.
- يمكن رفع الملفات الثلاثة `index.html`, `style.css`, `app.js` إلى جذر مستودع GitHub Pages.
